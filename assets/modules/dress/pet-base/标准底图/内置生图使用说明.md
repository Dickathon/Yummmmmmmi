# 内置生图使用说明

本文说明的是 Codex / Cursor 对话里的内置生图能力，不是 PowerShell 公开命令，也不是项目 Python 脚本。

## 基本理解

内置生图在**当前对话内部**调用：

1. 在对话里发起生图请求（附对应组件标准底图作参考）。
2. 后台生成图片。
3. 将生成图复制到项目目录，校验后保存为 `{食品名}_{组件名}.png`。

## 当前生图流程（在模板上直接生成）

**不再**单独生成透明装扮层 + 绿幕去底 + 手工叠底。

新流程：

1. 以对应组件 **1254 标准底图** 为参考（如躯干用 `body_1254.png`）。
2. **直接在模板上**为该组件绘制食物主题装扮（保留原组件本体）。
3. 复制生成图到 `assets/modules/dress/pet-layers/_tmp_*_builtin/` 留档。
4. 用 `validate_component_offset.py` 校验画布尺寸、锚点 bbox、透明角。
5. 通过后保存为 `assets/modules/dress/pet-layers/{组件名}/{食品名}_{组件名}.png`（按组件分子文件夹）。

### 常用请求格式（躯干示例）

```text
参考并直接编辑 body_1254.png。
只编辑躯干组件区域，在原有躯干模板上绘制装扮。
保持 1254×1254，躯干锚点绝对位置不动。
禁止补全头、脸、四肢、尾巴；透明区域保持透明。
设计：{食物主题描述}。
风格：装饰更大胆醒目，适配原猫插画风。
```

### 常用请求格式（头部示例）

```text
参考并直接编辑 head_1254.png。
只编辑头部组件区域，在原有头部模板上绘制装扮。
保持 1254×1254，头部锚点绝对位置不动。
禁止补全躯干、四肢、尾巴；透明区域保持透明。
设计：{食物主题描述}。
      在原猫头上添加可穿戴头饰，保留猫耳与脸型，不是整头替换成食物。
风格：装饰更大胆醒目，适配原猫插画风。
```

**后处理（必须，禁止裁切）**：

AI 原图保存到 `_tmp_head_builtin/{食品名}_头部_ai.png`，再执行：

```text
node wmx-temporary/tools/finalize_head_builtin.mjs \
  --source assets/modules/dress/pet-layers/_tmp_head_builtin/北京烤鸭_头部_ai.png \
  --out assets/modules/dress/pet-layers/头部/北京烤鸭_头部.png
```

finalize 会：抠除黑/白底 → 必要时整图缩放至 1254×1254（不裁切）→ 将 AI 装饰像素叠加到 `head_1254.png` 锚点底图上。

留档目录：`assets/modules/dress/pet-layers/_tmp_head_builtin/`

批量校验：

```text
node wmx-temporary/tools/validate_head_batch.mjs
```

## 甜品毯子（独立 AI 生图）

毯子**不与**头/躯干/四肢/尾巴同图生成。**禁止**使用 `generate_dessert_blankets.mjs` 等脚本程序化绘制；仅允许对话内置 AI 生图。

流程见 [`甜品装扮分配表.md`](../../甜品装扮分配表.md) 与 [`毯子锚点规范.md`](毯子锚点规范.md)。

**参考图**：

1. **必选**：`blanket_1254.png`（锁定椭圆位置与尺寸）
2. **可选风格参考**：`小鸡炖蘑菇_躯干.png`（仅学插画风，禁止出现躯干内容）

**提示词示例**：

```text
2D game dress-up asset, cute illustrated style matching orange tabby cat costume layers.
1254x1254 PNG, transparent background outside oval.
ONLY a horizontal oval floor mat/rug in the EXACT position and size of the cream ellipse in the reference image.
Food theme: 奶油蛋糕 — 粉白奶油蛋糕层纹椭圆毯，草莓粒点缀，奶油裱花边。
Soft cel-shading, clean outlines, decorative food textures on the mat surface.
NO cat, NO paws, NO legs, NO body, NO head, NO tail, NO background, NO text.
```

**后处理（必须）**：

AI 原图保存到 `_tmp_blanket_builtin/{食品名}_毯子_ai.png`，再执行：

```text
node wmx-temporary/tools/finalize_blanket_builtin.mjs \
  --source assets/modules/dress/pet-layers/_tmp_blanket_builtin/奶油蛋糕_毯子_ai.png \
  --out assets/modules/dress/pet-layers/毯子/奶油蛋糕_毯子.png
```

finalize 会：缩放到 1254×1254 → 按 `blanket_1254` 椭圆 mask 裁切 → 自动校验。

留档目录：`assets/modules/dress/pet-layers/_tmp_blanket_builtin/`

单独校验：

```text
node wmx-temporary/tools/validate_blanket_anchor.mjs \
  --candidate assets/modules/dress/pet-layers/毯子/奶油蛋糕_毯子.png
```

## 后处理与校验

```text
# 校验示例（需 Python + Pillow）
python wmx-temporary/tools/validate_component_offset.py \
  --component body \
  --reference assets/modules/dress/pet-base/标准底图/body_1254.png \
  --candidate assets/modules/dress/pet-layers/躯干/小鸡炖蘑菇_躯干.png
```

校验要点：

- 尺寸 `1254×1254`
- 四角 alpha = 0（透明底）
- 组件 bbox 相对标准底图无明显内缩偏移（`max_inward_shift` ≤ 3px）

若装扮轻微越界，可选用 `clamp_component_to_reference.py` 裁回锚点区域（一般直接生图流程较少需要）。

## 命名

`{食品名}_{组件名}.png`

- 组件名：`头部` / `躯干` / `四肢` / `尾巴` / `毯子`
- 食品名须与 [`js/data/foods.js`](../../../../js/data/foods.js) 白名单一致

示例：`小鸡炖蘑菇_躯干.png`、`北京烤鸭_头部.png`、`刀削面_尾巴.png`、`奶油蛋糕_毯子.png`
