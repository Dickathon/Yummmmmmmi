## 2. 已验证通过的稳定流程

本批四肢素材不再直接使用“透明底参考图 + 内置生图结果直接落盘”的方式。

原因：

1. 内置生图在读取透明底参考图时，容易把透明预览棋盘格错误烤进背景。
2. 直接去底后，AI 结果本身可能覆盖掉原始腿部结构，导致偏移校验失败。

当前已验证通过的稳定流程固定为：

1. 先将 `legs_1254.png` 和 `cat_full_1254.png` 处理为统一纯青色底参考图：
   `pictures\_tmp_legs_builtin\legs_1254_cyan.png`
   `pictures\_tmp_legs_builtin\cat_full_1254_cyan.png`
2. 使用内置生图编辑青色底参考图，要求背景保持纯青色单色，不允许棋盘格、白底、阴影底或文字。
3. 将最新原始生成图保存为：
   `pictures\_tmp_legs_builtin\食品名_四肢_cyan_raw.png`
4. 用 `remove_chroma_key.py` 去除纯青色背景，生成装饰层：
   `pictures\_tmp_legs_builtin\食品名_四肢_decor.png`
5. 使用 [finalize_legs_builtin.py](E:/微信开发者工具/Yummmmmmmi/wmx-temporary/tools/finalize_legs_builtin.py)
   将装饰层叠加回原始 `legs_1254.png`，保证原腿结构保底。
6. 使用 [validate_component_offset.py](E:/微信开发者工具/Yummmmmmmi/wmx-temporary/tools/validate_component_offset.py)
   做最终偏移校验，只保留 `PASS` 的正式成品。

## 4. 生成提示词固定约束

每张四肢图均沿用以下硬约束：

1. 画布必须保持 `1254x1254`。
2. 背景必须保持纯青色单色，便于后续抠图。
3. 只允许生成四肢组件，不得补全头、躯干、尾巴或背景。
4. 不得出现文字、汉字、字母、数字、标签、印章或任何可读符号。
5. 不得改变四条腿的原始锚点、朝向、间距、爪子可读性和前后腿层次关系。
6. 风格允许更大胆，但必须保持“可穿戴化装扮”，不能变成真实食物直接糊在腿上。

## 5. 验收标准

每张正式成品必须同时满足：

1. 输出文件位于 `pictures\四肢`。
2. 文件名符合 `食品名_四肢.png`。
3. 去底后四角 alpha 为 `0`，非组件区域透明。
4. 偏移校验脚本返回 `PASS`。
5. 肉眼检查没有以下问题：
   - 文字
   - 白底/棋盘底/实色背景残留
   - 明显偏移
   - 腿部结构丢失
   - 爪子被完全遮挡
   - 装扮主题与对应食物不符

## 6. 执行建议

1. 后续按“待完成”列表顺序逐张推进，避免跳项。
2. 每完成一张，立即运行 `finalize_legs_builtin.py`，不要积压到最后统一处理。
3. 正式目录 `pictures\四肢` 中只保留最终交付图；中间件统一留在 `pictures\_tmp_legs_builtin`。
