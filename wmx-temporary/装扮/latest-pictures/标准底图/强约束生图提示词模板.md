请完全依据参考图片进行 AI 生图编辑。核心目标是：**直接在当前目标组件的标准底图模板上**，为该组件生成食物主题装扮，输出一张可直接用于图层叠放的组件 PNG。

这个模板适用于每一个拆分组件（头 / 躯干 / 四肢 / 尾巴）。每次生图只针对当前输入的目标组件模板，不要编辑其他组件区域。

---

## 生图模式（当前默认）

**在组件模板上直接生成**，不是单独生成透明装扮层后再手工合成。

生图流程必须是：

1. 以对应组件的标准底图（如 `body_1254.png`）作为参考图与编辑底图；
2. 先识别并锁定参考图中当前目标组件在画布内的原始位置、轮廓、朝向、大小；
3. **仅在该组件区域内**添加或绘制食物主题装扮（服饰化、装饰化）；
4. 组件区域外的画布内容保持与参考图一致（透明处继续透明，不得新增长像素）。

最终输出是一张 **1254×1254 的组件图层 PNG**：包含原组件本体 + 其上的食物主题装扮，可直接替换或叠加使用。

---

## 定位要求

- 保留 **1254×1254** 原始画布尺寸，不要裁切、扩边、缩放或重设画布。
- 当前目标组件在画布内的 **绝对位置、轮廓、朝向、大小** 必须与参考图完全一致，视为固定锚点，不得平移、旋转、缩放或重新居中。
- 装扮主体必须落在原组件所在区域内；可沿组件边缘少量自然外扩（包边、飘带、小挂饰、护套、结饰），但不得明显超出该组件合理装扮范围。
- 装扮所有像素必须在画布内部，不得被画布边缘裁断。
- 不要把组件或装扮推向画布边角，不要改变组件与画布边界的相对关系。

---

## 生成要求

- **允许保留并输出原组件本体**，在其上直接绘制食物主题装扮（与旧版「仅装扮层」流程不同）。
- **禁止补全**当前组件之外缺失的头、脸、躯干、四肢、尾巴或其他部位；**禁止脑补完整宠物**。
- **禁止**在透明区域绘制任何新内容（除当前组件锚点范围内的装扮外，其余透明区域必须保持全透明）。
- **禁止**生成背景、文字、水印、白底、灰底或实色底。
- **禁止**输出穿戴预览整猫、禁止改变构图、禁止裁切透明区域。

## 美工要求（按当前食物替换 `{食物名}` 与 `{设计描述}`）

以 **{食物名}** 为灵感，为 **{当前组件名}** 设计装扮。

**每次生图前必须做简单设计**：从 [`主食装扮分配表.md`](../../主食装扮分配表.md) 或 [`甜品装扮分配表.md`](../../甜品装扮分配表.md)（毯子）取出该食物对应行的「装扮设计」，作为本次 `{设计描述}`；若需微调，仅在不改变食物辨识度的前提下略加强配色或纹样。

{设计描述}

**躯干专用要求**：
- 生成的是 **完整躯干服饰**（小褂、短袍、背心、罩衣、针织开衫等），不是单一围兜、胸甲或护胸片。
- 食物元素须 **直接体现在衣服本身**：印布、拼布、绗缝、织纹、满印、滚边、刺绣等，一眼可辨是哪种食物主题。
- 整体是 **可穿戴的上衣**，不是把食物块或锅具贴在猫身上。

**头部专用要求**：
- 生成的是 **可穿戴头饰**（帽、冠、头套饰边、领圈、小挂饰等），在原猫头组件上添加装饰。
- **保留**猫耳、脸型、朝向与原有头部轮廓，不是把整颗头替换成食物块。
- 食物元素须体现在帽冠、饰边、纹理、小徽章等，一眼可辨是哪种食物主题。
- 禁止补全脖子以下躯干/四肢/尾巴；装饰可沿头顶/耳侧少量自然外扩，但锚点 bbox 不得明显内缩。

**尾巴专用要求**：
- **保留**原猫尾本体，在其上/沿尾弧绘制**尾饰**（飘带、面条带、签子串、坠饰、螺旋卷等），不是裤子、围裙或独立食物堆。
- 食物元素须 **沿尾巴走向** 分布（弧带、层叠面片、螺旋、坠子），一眼可辨是哪种食物主题。
- 允许尾尖方向少量自然外扩，不得画成第二截身体或补全躯干连接处。
- 禁止补全头、脸、躯干、四肢；透明区域保持透明。

**通用要求**：
- 提取该食物的标志性颜色、纹理、层次与氛围，转化为服饰语言。
- 须与原角色插画风统一：线条、厚度、阴影、配色和质感适配原图。

**风格加粗（可选）**：装饰可更醒目——更高饱和度、更明确的满印/拼布纹样、更宽滚边，但仍须适配原猫插画风，不过度写实。

## 硬性约束

- 画布尺寸：**1254×1254** 不变。
- 组件锚点：位置、大小、朝向与参考图一致。
- 非组件区域：保持参考图原有透明（alpha = 0），不得新增像素。
- 禁止补全整猫、禁止生成其他身体部位、禁止移动组件坐标。
- 输出可直接保存为：`{食物名}_{组件名}.png`（组件名：头部 / 躯干 / 四肢 / 尾巴 / 毯子）。

## 毯子专用（独立图层，不与猫部件同图）

**适用**：13 种甜品，每种一张 `{食品名}_毯子.png`。设计见 [`甜品装扮分配表.md`](../../甜品装扮分配表.md)；锚点见 [`毯子锚点规范.md`](毯子锚点规范.md)。

**与躯干/四肢流程的关键差异**：

- 参考图为 `blanket_1254.png`（中性椭圆定位模板），**不是** `body_1254` / `legs_1254`。
- 输出**仅含椭圆毯子**，禁止绘制头、躯干、四肢、尾巴或整猫。
- 椭圆中心、半轴与参考模板 **完全一致**，13 张毯子外轮廓尺寸统一。
- 椭圆外区域保持全透明。

**毯子专用要求**：

- 形态为**水平椭圆**餐垫/地毯，食物主题体现在毯面纹样、配色与边缘装饰。
- 禁止补全任何猫身体部位。
- 叠放时毯子为**最底层**（低于 tail）。
