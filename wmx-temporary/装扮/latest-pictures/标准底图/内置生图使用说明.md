# 内置生图使用说明

本文说明的是 Codex / Cursor 对话里的内置生图能力，不是 PowerShell 公开命令，也不是项目 Python 脚本。

## 基本理解

内置生图在**当前对话内部**调用：

1. 在对话里发起生图请求（附对应组件标准底图作参考）。
2. 后台生成图片。
3. 将生成图复制到项目目录，校验后保存为 `{食品名}_{组件名}.png`。

## 当前生图流程（在模板上直接生成）

**不再**单独生成透明装扮层 + 绿幕去底 + 手工叠底。

新流程：

1. 以对应组件 **1254 标准底图** 为参考（如躯干用 `body_1254.png`）。
2. **直接在模板上**为该组件绘制食物主题装扮（保留原组件本体）。
3. 复制生成图到 `wmx-temporary/装扮/pictures/_tmp_*_builtin/` 留档。
4. 用 `validate_component_offset.py` 校验画布尺寸、锚点 bbox、透明角。
5. 通过后保存为 `wmx-temporary/装扮/pictures/{食品名}_{组件名}.png`。

### 常用请求格式（躯干示例）

```text
参考并直接编辑 body_1254.png。
只编辑躯干组件区域，在原有躯干模板上绘制装扮。
保持 1254×1254，躯干锚点绝对位置不动。
禁止补全头、脸、四肢、尾巴；透明区域保持透明。
设计：{食物主题描述}。
风格：装饰更大胆醒目，适配原猫插画风。
```

## 后处理与校验

```text
# 校验示例（需 Python + Pillow）
python wmx-temporary/tools/validate_component_offset.py \
  --component body \
  --reference wmx-temporary/装扮/latest-pictures/标准底图/body_1254.png \
  --candidate wmx-temporary/装扮/pictures/小鸡炖蘑菇_躯干.png
```

校验要点：

- 尺寸 `1254×1254`
- 四角 alpha = 0（透明底）
- 组件 bbox 相对标准底图无明显内缩偏移（`max_inward_shift` ≤ 3px）

若装扮轻微越界，可选用 `clamp_component_to_reference.py` 裁回锚点区域（一般直接生图流程较少需要）。

## 命名

`{食品名}_{组件名}.png`

- 组件名：`头部` / `躯干` / `四肢` / `尾巴`
- 食品名须与 [`js/data/foods.js`](../../../../js/data/foods.js) 白名单一致

示例：`小鸡炖蘑菇_躯干.png`、`北京烤鸭_头部.png`
