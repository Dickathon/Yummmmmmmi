# 主食装扮分配表

适用目录：`E:\微信开发者工具\Yummmmmmmi\wmx-temporary\装扮`

本文件用于明确宠物装扮方案中食物类型与装饰部件的对应关系，便于后续进行素材制作、命名和分工协作。

## 1. 对应规则

本轮装扮方案采用以下固定映射：

1. `主食`：用于宠物身上的装扮部件
2. `甜品`：用于地毯元素
3. `饮品`：用于猫粮碗中的食物元素

宠物身上的装扮部件固定为以下四类：

1. `躯干`
2. `四肢`
3. `头部`
4. `尾巴`

## 2. 依据来源

主食白名单以项目内以下文件为准：

1. [js/data/foods.js](E:/微信开发者工具/Yummmmmmmi/js/data/foods.js)
2. [Project Specification.md](E:/微信开发者工具/Yummmmmmmi/Project%20Specification.md)
3. [README.md](E:/微信开发者工具/Yummmmmmmi/README.md)

说明：

1. 食物名必须严格使用项目白名单中的正式名称。
2. 不得自行改名、替换同义词、使用简称或增加修饰词。
3. `酥油茶` 虽然日常理解接近饮品，但在本项目白名单中归类于 `主食`，因此本文件仍将其分配为宠物身上装扮元素。

## 3. 分配原则

本表主要按食物视觉形态做分配，便于后续生成或绘制装扮素材：

1. `尾巴`：优先分配细长、卷曲、拖尾感明显的食物。
2. `头部`：优先分配圆盘、锅碗、夹层、冠饰感较强的食物。
3. `四肢`：优先分配小块状、重复件、护腕护腿感较强的食物。
4. `躯干`：优先分配体量大、包裹感强、适合覆盖胸腹和背部的食物。

## 6. 后续执行建议

1. 素材命名时，食物字段直接使用本表中的正式食物名。
2. 如需进入正式素材流，建议命名格式统一为：`[component]_[canvas]_[food_name].png`
3. 示例：`body_1024_红烧肉.png`、`head_1024_北京烤鸭.png`、`tail_1024_炸酱面.png`
4. 如果后续需要保留版本信息，可追加统一后缀：`[component]_[canvas]_[food_name]_[variant].png`
