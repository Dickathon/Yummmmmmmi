# 主食躯干生图执行计划

适用目录：`E:\微信开发者工具\Yummmmmmmi\wmx-temporary\装扮\pictures`

## 1. 目标

本轮只产出主食分类中的 `躯干` 装扮组件，统一基于 `1254x1254` 标准躯干底图进行内置生图，并输出正式透明底 PNG。

正式命名固定为：

`食品名_躯干.png`

示例：

1. `锅包肉_躯干.png`
2. `小鸡炖蘑菇_躯干.png`

## 2. 固定参考

执行时始终使用以下参考：

1. `pictures\标准底图\body_1254.png`
2. `pictures\标准底图\cat_full_1254.png`
3. `pictures\标准底图\强约束生图提示词模板.md`

说明：

1. `body_1254.png` 只作为躯干锚点参考。
2. `cat_full_1254.png` 只作为整体风格和条纹逻辑参考。
3. 不再使用旧的 `1024` generation kit 作为最终画布标准。

## 3. 统一流水线

每张图固定按以下顺序执行：

1. 内置生图生成一张带纯色抠图底的候选图。
2. 原始生图先保存到 `pictures\_tmp_torso_generation\食品名_躯干_raw.png`
3. 使用 `C:\Users\27533\.codex\skills\.system\imagegen\scripts\remove_chroma_key.py` 去底。
4. 输出去底结果到 `pictures\_tmp_torso_generation\食品名_躯干.png`
5. 使用 `wmx-temporary\tools\validate_component_offset.py` 做偏移校验。
6. 偏移校验通过后，再复制到 `pictures\食品名_躯干.png`
7. 偏移校验失败或肉眼明显不合规时，直接废弃当前候选，重新生成。

执行注意：

1. 去底与偏移校验必须串行执行，不要并行。
2. 候选图未成功写入前，不要提前启动校验。
3. 系统 `python.exe` 当前不可依赖，统一使用线程内置运行时：

`C:\Users\27533\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe`

## 4. 验收规则

每张图都必须满足：

1. 画布固定为 `1254x1254`
2. 四角 alpha 为 `0`
3. 不补全头、腿、尾或整猫
4. 颈部开口、背弧、右臀轮廓、下沿两个腿根缺口保持原位
5. 允许沿外轮廓轻微外长，但不能整体下沉或错位
6. 看起来是“穿在猫身上的主题装扮”，不是整块食物贴图
7. 不允许背景、文字、水印、棋盘透明预览纹

偏移校验标准：

1. 默认 `--max-shift 3`
2. 默认 `--alpha-threshold 12`
3. 默认 `--max-missing-ratio 0.02`
